# Spice Bitz POS — Modern Fast Food Billing System

A modern Point of Sale (POS) and billing web application designed for fast food restaurants and cafes with quick item selection and invoicing.

## Features

- Touch-friendly fast food menu grid with categorized items (Burgers, Pizzas, Snacks, Beverages)
- Current order cart with live quantity adjustment, subtotals, and tax calculations
- Quick checkout workflow with cash, card, and UPI payment simulation
- Printable receipt generator formatted for thermal printers
- Daily sales dashboard tracking total revenue and completed order counts
- Data persistence using browser LocalStorage

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- Font Awesome
- LocalStorage API

## Installation & Setup

This is a standalone, client-side web application. No complex build pipelines, database configurations, or package installations are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SSManikandaprabu/spice-bitz-pos.git
   cd spice-bitz-pos
   ```

2. **Run the application:**
   - **Direct Browser Launch**: Double-click `spice bitz.html` to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).
   - **Or via Local HTTP Server**:
     ```bash
     python -m http.server 8000
     ```
     Then open [http://localhost:8000/spice bitz.html](http://localhost:8000/spice bitz.html) in your browser.

## Usage

1. Launch the application in your browser following the setup instructions above.
2. Interact with the application controls and input fields tailored for Spice Bitz POS — Modern Fast Food Billing System.
3. Preferences and data are stored locally in your browser's LocalStorage where applicable.
